Native Select wraps Expo UI's [Picker](https://docs.expo.dev/versions/latest/sdk/ui/universal/picker/). Without `NativeSelectInput`, it renders the menu or wheel control directly. With `NativeSelectInput`, iOS defaults to a wheel bottom sheet (`appearance="menu"` uses a non-pressable input with the native menu picker); Android uses ActionInput as an [`ExposedDropdownMenuBox`](https://docs.expo.dev/versions/latest/sdk/ui/jetpack-compose/exposeddropdownmenubox/) anchor.

## Usage

### Menu and wheel

Omit `NativeSelectInput` to render the Expo Picker directly. Set `appearance` on the root (`menu` or `wheel`). `appearance="wheel"` is iOS-only; on Android it falls back to the platform menu.

```tsx
import {
  NativeSelect,
  NativeSelectItem,
} from "@/components/ui/native-select";
```

```tsx
const [value, setValue] = useState("1");

<NativeSelect appearance="menu" value={value} onValueChange={setValue}>
  <NativeSelectItem label="Option 1" value="1" />
  <NativeSelectItem label="Option 2" value="2" />
  <NativeSelectItem label="Option 3" value="3" />
</NativeSelect>
```

```tsx
<NativeSelect appearance="wheel" value={value} onValueChange={setValue}>
  <NativeSelectItem label="Option 1" value="1" />
  <NativeSelectItem label="Option 2" value="2" />
  <NativeSelectItem label="Option 3" value="3" />
</NativeSelect>
```

### NativeSelectInput

Renders form-styled input chrome. Use `appearance` to choose the iOS presentation:

- **`wheel` (default)** — ActionInput that opens a bottom sheet containing a wheel picker
- **`menu`** — non-pressable input chrome; only the native menu picker is tappable
- **Android** — ActionInput as the [`ExposedDropdownMenuBox`](https://docs.expo.dev/versions/latest/sdk/ui/jetpack-compose/exposeddropdownmenubox/) anchor via `menuAnchor()` (Material menu). `appearance` is ignored.

Pass `InputAddon` children for `inline-start` / `inline-end` adornments. On iOS wheel, optionally compose `NativeSelectSheetFooter` and `NativeSelectSheetConfirm` to require an explicit confirm before committing (dismiss cancels).

```tsx
import { Button } from "@/components/ui/button";
import {
  NativeSelect,
  NativeSelectInput,
  NativeSelectItem,
  NativeSelectSheetConfirm,
  NativeSelectSheetFooter,
} from "@/components/ui/native-select";
import { InputAddon, InputAddonIcon } from "@/components/ui/input";
import { SearchIcon } from "@/components/ui/icons";
```

```tsx
<NativeSelect value={value} onValueChange={setValue}>
  <NativeSelectInput placeholder="Select...">
    <InputAddon align="inline-start">
      <InputAddonIcon>
        <SearchIcon />
      </InputAddonIcon>
    </InputAddon>
    <NativeSelectItem label="Option 1" value="1" />
    <NativeSelectItem label="Option 2" value="2" />
    <NativeSelectItem label="Option 3" value="3" />
    <NativeSelectSheetFooter>
      <NativeSelectSheetConfirm asChild>
        <Button>Confirm</Button>
      </NativeSelectSheetConfirm>
    </NativeSelectSheetFooter>
  </NativeSelectInput>
</NativeSelect>
```

```tsx
<NativeSelect value={value} onValueChange={setValue}>
  <NativeSelectInput appearance="menu" placeholder="Select...">
    <NativeSelectItem label="Option 1" value="1" />
    <NativeSelectItem label="Option 2" value="2" />
    <NativeSelectItem label="Option 3" value="3" />
  </NativeSelectInput>
</NativeSelect>
```

Without a sheet footer, iOS wheel commits the value as it changes.
## Controlled

Pass `value` and `onValueChange` for controlled selection. On iOS, optionally control `open` and `onOpenChange` for the sheet:

```tsx
const [value, setValue] = useState("1");
const [open, setOpen] = useState(false);

<NativeSelect
  value={value}
  onValueChange={setValue}
  open={open}
  onOpenChange={setOpen}
>
  <NativeSelectInput placeholder="Select...">
    <NativeSelectItem label="Option 1" value="1" />
    <NativeSelectItem label="Option 2" value="2" />
  </NativeSelectInput>
</NativeSelect>
```

## Disabled

```tsx
<NativeSelect disabled value={value} onValueChange={setValue}>
  <NativeSelectInput placeholder="Select...">
    <NativeSelectItem label="Option 1" value="1" />
    <NativeSelectItem label="Option 2" value="2" />
  </NativeSelectInput>
</NativeSelect>
```

## API Reference

### NativeSelectSheetFooter

Accepts [`BottomSheetFooter`](/docs/components/bottom-sheet) props. When present on iOS `wheel`, picker changes are drafted until confirm; dismiss cancels.

### NativeSelectSheetConfirm

Extends [React Native Pressable](https://reactnative.dev/docs/pressable#props) props. Commits the draft value and closes the sheet. Must be used within `NativeSelect`.

## Changelog

### 2026-08-02 - Menu appearance on NativeSelectInput

`NativeSelectInput` accepts `appearance`. On iOS, `menu` uses non-pressable input chrome with only the native menu picker interactive; `wheel` (default) keeps the bottom sheet.

### 2026-08-01 - Android input chrome + sheet confirm

Android `NativeSelectInput` uses `ExposedDropdownMenuBox` with ActionInput as the `menuAnchor`, so the Material TextField is no longer nested inside tetra input chrome. Add `NativeSelectSheetFooter` and `NativeSelectSheetConfirm` for an explicit confirm action on the iOS wheel sheet. When present, wheel changes are drafted until confirm; dismiss cancels.

### 2026-07-31 - Initial release

Add `NativeSelect`, `NativeSelectInput`, and `NativeSelectItem` built on Expo UI Picker. `NativeSelectInput` uses a wheel bottom sheet on iOS and an `ExposedDropdownMenuBox` with custom input chrome on Android.
