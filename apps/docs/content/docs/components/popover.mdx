## Usage

First ensure that you have [`ScrimHost`](/docs/components/scrim) and `PortalHost` in your root layout. `ThemeProvider` already includes both.

```tsx
import { PortalHost } from "@/components/ui/portal";
import { ScrimHost, ScrimTarget } from "@/components/ui/scrim";

export default function RootLayout() {
  return (
    <ScrimHost>
      <ScrimTarget>
        <Stack />
      </ScrimTarget>
      <PortalHost />
    </ScrimHost>
  );
}
```

```tsx
import { Button, ButtonText } from "@/components/ui/button";
import {
  Popover,
  PopoverContent,
  PopoverPortal,
  PopoverScrim,
  PopoverTrigger,
} from "@/components/ui/popover";
```

```tsx
<Popover>
  <PopoverTrigger asChild>
    <Button>
      <ButtonText>Open</ButtonText>
    </Button>
  </PopoverTrigger>
  <PopoverPortal>
    <PopoverScrim />
    <PopoverContent>
      <Text>Popover Content</Text>
    </PopoverContent>
  </PopoverPortal>
</Popover>
```

## Positioning

Control placement with `side` and `align` on `PopoverContent`:

```tsx
<PopoverContent side="top" align="center">
  <Text>Tooltip above the trigger</Text>
</PopoverContent>
```

Supported values:

- `side`: `"top"` | `"bottom"` | `"left"` | `"right"`
- `align`: `"start"` | `"center"` | `"end"` (defaults to `"center"`)

Use `sideOffset` and `alignOffset` to fine-tune distance from the trigger. By default `width="fit"` sizes to the content and wraps long text at 280px so the popover stays compact. Set `width="trigger"` to match the trigger width, or pass a percentage or pixel value.

## Without scrim

Omit `PopoverScrim` for lightweight tooltips that don't dim the background:

```tsx
<Popover>
  <PopoverTrigger asChild>
    <Button variant="outline">Open</Button>
  </PopoverTrigger>
  <PopoverPortal>
    <PopoverContent>
      <Text>No scrim</Text>
      <PopoverClose asChild>
        <Button size="sm" variant="link">Close</Button>
      </PopoverClose>
    </PopoverContent>
  </PopoverPortal>
</Popover>
```

## Controlled

Pass `open` and `onOpenChange` for controlled state:

```tsx
const [open, setOpen] = useState(false);

<Popover open={open} onOpenChange={setOpen}>
  {/* ... */}
</Popover>
```

## Scrollable content

Wrap long content in a `ScrollView` and constrain the popover height:

```tsx
<PopoverContent className="h-1/2 p-0" width="50%">
  <ScrollView className="p-4">
    {/* long content */}
  </ScrollView>
</PopoverContent>
```


## API Reference

### Popover

Root open state. Controlled when `open` is set.

    },
  }}
/>

### PopoverTrigger

Extends [React Native Pressable](https://reactnative.dev/docs/pressable#props) props. Measures itself and opens the popover on press. Must be used within `Popover`.

  type={{

      type: "boolean",
    },
  }}
/>

### PopoverClose

Extends [React Native Pressable](https://reactnative.dev/docs/pressable#props) props. Closes the popover on press. Must be used within `Popover`.

<TypeTable
  type={{
    asChild: {
      description: "Merges props onto the child via `Slot.Pressable` instead of rendering a Pressable.",
      type: "boolean",
    },
  }}
/>

### PopoverPortal

Accepts [`Portal`](/docs/components/portal) props. Renders nothing when closed. Must be used within `Popover`.

[`Scrim`](/docs/components/scrim) wired to popover open state. Must be used within `Popover` (typically inside `PopoverPortal`).
