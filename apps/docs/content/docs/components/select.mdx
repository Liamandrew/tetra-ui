## Usage

First ensure that you have the `PortalHost` component in your root layout.

```tsx
import { PortalHost } from "@/components/ui/portal";

export default function RootLayout() {
  return (
    <>
      <Stack />
      <PortalHost />
    </>
  );
}
```

```tsx
import { Button } from "@/components/ui/button";
import {
  Select,
  SelectContentSheet,
  SelectContentSheetBody,
  SelectContentSheetConfirm,
  SelectContentSheetFooter,
  SelectContentSheetHeader,
  SelectContentSheetTitle,
  SelectInput,
  SelectItem,
  SelectItemIndicator,
  SelectItemLabel,
  SelectTrigger,
} from "@/components/ui/select";
```

```tsx

const OPTIONS = [
  { label: "Option 1", value: "1" },
  { label: "Option 2", value: "2" },
  { label: "Option 3", value: "3" },
];

<Select options={OPTIONS} placeholder="Select...">
  <SelectTrigger asChild>
    <SelectInput />
  </SelectTrigger>
  <SelectContentSheet>
    <SelectContentSheetHeader>
      <SelectContentSheetTitle>Select a value</SelectContentSheetTitle>
    </SelectContentSheetHeader>
    <SelectContentSheetBody>
      {OPTIONS.map((option) => (
        <SelectItem
          key={option.value}
          label={option.label}
          value={option.value}
        />
      ))}
    </SelectContentSheetBody>
    <SelectContentSheetFooter>
      <SelectContentSheetConfirm asChild>
        <Button>Confirm</Button>
      </SelectContentSheetConfirm>
    </SelectContentSheetFooter>
  </SelectContentSheet>
</Select>
```

## Controlled

Pass `value` and `onValueChange` for controlled selection:

```tsx
const [value, setValue] = useState<string>();

<Select
  options={OPTIONS}
  value={value}
  onValueChange={setValue}
  placeholder="Select..."
>
  {/* ... */}
</Select>
```

## Invalid

Pass `invalid` to show a destructive border on the trigger input:

```tsx
<Select options={OPTIONS} invalid placeholder="Select...">
  {/* ... */}
</Select>
```

## Popover content

For shorter option lists, use `SelectContentPopover` instead of a sheet:

```tsx
<Select options={OPTIONS} placeholder="Select...">
  <SelectTrigger asChild>
    <SelectInput />
  </SelectTrigger>
  <SelectContentPopover>
    {OPTIONS.map((option) => (
      <SelectItem
        key={option.value}
        label={option.label}
        value={option.value}
      />
    ))}
  </SelectContentPopover>
</Select>
```

When using popover content, `PortalHost` must be present in your root layout.

### SelectTrigger

Extends [React Native Pressable](https://reactnative.dev/docs/pressable#props) props. Toggles open and records trigger layout for popover positioning. Must be used within `Select`.

<TypeTable
  type={{

      type: "boolean",
    },
  }}
/>

### SelectInput

Accepts partial [`ActionInput`](/docs/components/action-input) props. Shows the selected option label, placeholder, chevron, and focus/disabled/invalid from `Select` context. Must be used within `Select`.

### SelectItem

Extends [React Native Pressable](https://reactnative.dev/docs/pressable#props) props except `onPress` (managed). In popover mode, press commits immediately; in sheet mode, press updates the draft selection. Must be used within `Select`.

  }}
/>

### SelectItemLabel

Extends [`Text`](/docs/components/text) props.

### SelectItemIndicator

Renders a check icon when the item matches the draft selection. Must be used within `SelectItem`.

### SelectContentSheet

Renders options in a [`BottomSheet`](/docs/components/bottom-sheet). Sheet open state is bound to `Select`; dismiss cancels the draft.

### SelectContentSheetHeader

Alias of [`BottomSheetHeader`](/docs/components/bottom-sheet).

### SelectContentSheetTitle

Alias of [`BottomSheetTitle`](/docs/components/bottom-sheet).

### SelectContentSheetBody

Alias of [`BottomSheetBody`](/docs/components/bottom-sheet).

### SelectContentSheetFooter

Alias of [`BottomSheetFooter`](/docs/components/bottom-sheet).

### SelectContentSheetConfirm

Extends [React Native Pressable](https://reactnative.dev/docs/pressable#props) props. Commits the draft selection and closes the sheet. Must be used within `Select`.

  type={{

### SelectContentPopover

Accepts [`PopoverContent`](/docs/components/popover) props. Renders options in a popover (requires [`PortalHost`](/docs/components/portal)). Selecting an item commits immediately.
